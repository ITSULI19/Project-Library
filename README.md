# 📚 Project: Library

**Project: Library** es una aplicación web sencilla creada con HTML, CSS y JavaScript puro. Permite a los usuarios gestionar una biblioteca personal de libros, agregarlos, eliminarlos y marcar su estado de lectura.

## 🚀 Características

- Agregar libros con título, autor, número de páginas y estado de lectura.
- Renderizado dinámico de los libros en tarjetas.
- Eliminar libros de la biblioteca.
- Alternar entre leído / no leído.
- Interfaz moderna y responsive.
- Cada libro tiene un `id` único generado con `crypto.randomUUID()`.

## 🧠 Tecnologías usadas

- HTML5
- CSS3 (moderno y responsive)
- JavaScript (ES6+)
